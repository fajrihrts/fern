# Image Assets

Letakkan file gambar berikut di folder ini:

- `brand.png` - Logo BPS PPU (untuk header & footer)
- `favicon.png` - Favicon website
- `avatar.png` - Gambar hero section homepage
- `default-avatar.png` - Avatar default untuk testimoni tanpa foto

## Ukuran Rekomendasi

- brand.png: 200x60px (transparent PNG)
- favicon.png: 32x32px atau 64x64px
- avatar.png: 500x500px
- default-avatar.png: 200x200px
